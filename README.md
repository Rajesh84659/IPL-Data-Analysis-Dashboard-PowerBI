# 🏏 IPL Data Analysis Dashboard | Power BI

## 📌 Project Overview

This project is an end-to-end IPL data analytics dashboard built using **Power BI**, **DAX**, and **Python**. The dashboard provides comprehensive insights into team performance, batting records, bowling achievements, and match-winning patterns across multiple IPL seasons.

The objective of this project was to transform raw IPL match data into an interactive analytics solution that enables users to explore season-wise trends and performance metrics through dynamic visualizations.

---

## 🚀 Project Workflow

### 1️⃣ Data Collection

* Downloaded IPL historical data from publicly available web sources in **JSON format**.
* Collected data covering multiple IPL seasons, matches, players, and ball-by-ball records.

### 2️⃣ Data Transformation

* Used **Python** to convert JSON files into structured **CSV datasets**.
* Performed initial cleaning and formatting to make the data suitable for analysis.

### 3️⃣ Data Modeling

* Imported datasets into Power BI.
* Established relationships between match-level and ball-by-ball datasets.
* Created a star-schema style data model for efficient reporting.

### 4️⃣ DAX Development

* Built numerous custom **DAX Measures** and calculations to derive advanced cricket statistics.
* Implemented season-based filtering and dynamic KPI calculations.

### 5️⃣ Dashboard Development

* Designed an interactive 4-page Power BI report with a season slicer available across all pages.
* Created analytical visuals focused on batting, bowling, team performance, and match outcomes.
